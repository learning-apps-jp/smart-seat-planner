# スマート席替え 2.1

配布用の `smart_seat_planner_v21_completed.html`（または同内容の `index.html`）をダブルクリックし、Edge または Chrome で開いて使います。アプリ本体は1ファイルで完結し、インターネット接続やインストールは不要です。Downloads 内の元ファイルは変更していません。

## 最初の使い方

1. 「名簿設定」に名簿を貼り付けます。推奨順序は **出席番号、氏名、ふりがな、性別** のタブ区切りです。性別・ふりがなは任意です。表計算からの貼り付けに対応します。引用符付きCSVは未対応です。
2. 列数・行数と「使用しない席」を設定し、「整列」で全員を配置します。未配置者は一覧に表示され、空席を選んで個別配置できます。
3. 配慮が必要な生徒を手動で配置し、鍵ボタンで固定してから「ランダム席替え」を実行します。固定された空席も維持します。
4. 席を2つ選ぶと交換できます。Tab＋Enter／Spaceでも操作できます。固定席を移動する場合は先に固定を解除します。
5. 「元に戻す」「やり直す」で最大30件の操作を戻せます。名簿入力中は通常の文字編集用ショートカットが使えます。
6. 終了前に「バックアップ」でJSONを保存します。「読込」で復元できます。印刷・PDFは掲示用で、固定情報は出しません。

## 保存と個人情報

初期状態は端末への自動保存OFFです。OFFのままタブを閉じると、バックアップしていない変更は失われます。自動保存を使うときは「この端末に名簿・座席を自動保存する」を選びます。保存失敗は画面に表示します。

共有端末では使用後に「端末の保存データを削除」を押し、タブも閉じてください。削除操作はこのアプリのブラウザー保存だけが対象で、画面の内容・ダウンロードしたJSON・PDFは残ります。JSONとPDFには氏名が含まれます。保存先や共有先は勤務先の運用に合わせてください。暗号化や利用者認証は備えていません。

旧版の保存データがある場合は自動保存をONにして復元を選べます。別のブラウザー・端末・ファイルパスでは保存領域が異なることがあるため、移行にはJSONを使ってください。

## 今回の改善

- 不正・過大なJSON、重複番号／配置、範囲外の席を拒否し、読込失敗時は元の状態を維持。
- 列ごとの班境界を正しく復元。保存失敗を表示。
- 名簿で同じ番号を別人に置き換えた場合は、その人への座席・固定の引継ぎを解除。
- 席不足の席替えを中止し、未配置者を明示。
- 列間隔だけの変更では列別の行数を維持。レイアウト縮小で外れた人は未配置に戻す。
- 履歴、キーボード操作、ダイアログのフォーカス移動、ズーム、狭い画面での横スクロールを追加。
- 性別色分けを任意化し、初期OFF。班境界の席上操作は「班境界を編集する」で表示。
- 教師目線での通路位置、最大10列×12行のPDF／印刷を修正。

班人数は境界線の目安です。3席グループ、端の余り、使用しない席、独立した境界編集などでは表示名どおりの人数になりません。健康上・人間関係上の条件を自動最適化する機能はありません。必要な配置は教員が確認して固定してください。

## 検証範囲

データ検証20件、名簿・配置8件、120席の全通路設定×両視点の描画検証、Windows Edgeのブラウザー統合テストに合格しています。テスト時は自動生成した架空名簿を使用し、実在の児童生徒の情報は使用していません。検証中のアプリから外部へのHTTP通信はありませんでした。

iPad／Safari／Firefoxの実機と学校の実プリンターは未検証です。導入前に勤務先端末で架空名簿を使い、再起動後の保存・復元、印刷、日本語の表示を確認してください。

## 開発と再ビルド

`src/base.html` は提供版の原本コピーです。改善コードは用途別のJS/CSSに分け、`node build.cjs` で単一HTMLへ統合します。生成された `index.html` を直接編集すると再ビルドで上書きされます。

検証コマンド：

```text
node data-safety.test.cjs
node tests/roster-seating.test.cjs
node test-output.cjs
node tests/browser.cjs
```

ブラウザーテストはこの作業環境のPlaywrightパスとEdgeを使います。他環境では `tests/browser.cjs` の依存パスを変更してください。実行結果と画面キャプチャは `test-results/` に生成します。
